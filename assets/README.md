# Identidade visual

`orkut-digger-logo.png`: logo original criada para o projeto com a ferramenta integrada de geração de imagens. Fundo transparente; os ícones em `../icons/` são reduções com filtro Lanczos.

## Prompt de geração

Use case: logo-brand. Create one polished standalone square app icon for Orkut Digger, a Firefox and Chrome extension for historical research that excavates archived Orkut communities and exports topics and replies. A bold minimal magnifying glass integrated with a lowercase rounded o / community-node motif, suggesting discovery of archived conversations. Friendly early-web character, vivid Orkut-inspired magenta with deep violet accents; strong clean silhouette, thick shapes legible at 32 pixels, centered generous safe margins. Flat vector-like graphic, actual transparent background. No text, no letters other than the abstract o shape, no mockup, no gradients, no shadow, no watermark. Single final icon only.
